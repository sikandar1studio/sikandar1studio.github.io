02 / DESIGN APPROACH

From intention
to experience.

An Eid greeting leads into the question and four translucent stacked choices. A separate circular home control sits below the response area.

01

Greeting above the question

The second artboard asks an Eid-related question and presents four full-width rounded response buttons.

02

Four stacked choices

The composition retains a prominent Eid Mubarak calligraphic greeting, patterned green background and separate circular home control.

03

Separate home action

Companion native artboards contain a start prompt and additional question states; this establishes planned screen flow without proving executable quiz behavior.
