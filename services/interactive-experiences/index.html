WHAT WE CAN MAKE

From a first glance to one more round.

An event interaction has to explain itself quickly. The invitation, instructions, play state and ending all need to make sense in a real space. My work connects interface design, game presentation and creative development, with the hardware and delivery requirements established at the start. I am based in Riyadh and work with briefs for events, exhibitions and brand experiences.

01

Event games & activations

Branded game concepts and screen journeys built around a defined audience, session length and interaction.

02

Touchscreen & kiosk experiences

Invitations, selection screens, quizzes and content flows designed for use in an exhibition or shared space.

03

Shared-screen & phone controls

Experiences that separate the main display from personal controls, with clear player identity and readable actions.

HOW WE GET THERE

A clear process.
Room to explore.

  1. 01

    Understand the venue

    Establish the audience, viewing distance, expected queue and available screens or controllers.

  2. 02

    Map every state

    Define the invitation, joining flow, instructions, play, result and reset before polishing individual screens.

  3. 03

    Develop the experience

    Build the agreed visuals and interactive elements, then review clarity, feedback and pacing.

  4. 04

    Plan the on-site check

    Agree hardware integration, rehearsal and operator handoff explicitly. Installation and event support are scoped separately.

BEFORE WE BEGIN

A few useful
answers.

Can participants use phones as controllers?+

Phone-controlled experiences can be part of a brief. The venue network, supported devices, joining flow and recovery from disconnections need to be tested as part of the implementation scope.

Can you adapt an experience to a brand?+

Yes. Share the brand assets, tone, content and approval requirements. The work can cover the visual world and interface flow as well as the agreed interactive behavior.

Does a case study prove an installation is ready to deploy?+

The case studies explain the evidence shown: artwork, renders, captured interfaces or animation. A new live installation requires its own implementation, hardware integration and venue testing.
