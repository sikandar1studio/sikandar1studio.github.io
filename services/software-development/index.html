WHAT WE CAN MAKE

Software shaped around the way you work.

A useful tool begins with a specific job: moving a file through a process, reviewing an output, helping a team find information, or giving a customer a simpler way to act. I work from that job outward, defining the essential screens and interactions before expanding the feature set. Based in Riyadh, I collaborate on projects locally and remotely.

BEFORE WE BEGIN

A few useful
answers.

Can you build a tool around an existing workflow?+

Yes. A clear example of the current process is a useful starting point. The discovery stage identifies which steps should be automated, which need a human decision, and which integrations require separate access.

Do you use AI when building software?+

Yes, AI-assisted development is part of my practice. The project still needs a clear scope, reviewable code, testing and a deliberate user experience. Third-party models, tools and libraries retain their own credits and licensing requirements.

Is deployment and ongoing support included?+

Those are agreed per project. The brief should define where the application runs, who owns its accounts, and what support is needed after handoff. An interface prototype and a maintained production service have different scopes.
