# Sikandar Riaz — portfolio

Live at https://sikandar.work

A responsive static portfolio for design, interactive experiences, software, motion and 3D visualization.

This repository contains the complete public website: 174 visual case studies, the homepage, project browser, presentation code and optimized media. Private research, source project files and held material stay outside this repository.

## Hosting

GitHub Pages serves the main branch from the repository root. `.nojekyll` preserves the static files; `CNAME` defines the custom domain.

## Contact

Contact enquiries are delivered by Web3Forms with server-side hCaptcha verification. The form identifier is intentionally public, not an API secret. No email passwords or sending credentials are embedded.

## Media

Responsive WebP images and optimized viewer copies preserve each composition. Animation includes a static alternative for reduced-motion preferences. Original artwork remains in the local working archive.
